2. Instalación Paso a Paso

1Instalar Python

Descarga e instala Python desde python.org

Verifica la instalación:

python --version
# Debe mostrar: Python 3.10.x o superior

2Instalar MongoDB

Descarga MongoDB Community Server desde mongodb.com

Windows:
# Ejecutar el instalador .msi
# Instalar como servicio de Windows
# Puerto por defecto: 27017
Linux:
sudo apt-get update
sudo apt-get install -y mongodb-org
sudo systemctl start mongod
sudo systemctl enable mongod

Verificar instalación:

mongod --version

3Clonar el Proyecto

# Opción 1: Clonar desde Git (si está en repositorio)
git clone https://github.com/tu-usuario/restaurante-reservas.git
cd restaurante-reservas

# Opción 2: Descomprimir archivo ZIP
unzip restaurante-reservas.zip
cd restaurante-reservas

4Crear Entorno Virtual

# Windows
python -m venv venv
venv\\Scripts\\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
✅ Verificar: El prompt debe mostrar (venv) al inicio

5Instalar Dependencias

# Actualizar pip
python -m pip install --upgrade pip

# Instalar todas las dependencias
pip install -r requirements.txt
📝 Nota: Si no existe requirements.txt, instala manualmente: 
pip install django==6.0.1
pip install mongoengine
pip install reportlab
pip install django-cors-headers

6Configurar Variables de Entorno

Crea un archivo .env en la raíz del proyecto:

# .env
DEBUG=True
SECRET_KEY=tu-clave-secreta-django-aqui
MONGODB_NAME=restaurante_db
MONGODB_HOST=localhost
MONGODB_PORT=27017

7Crear Base de Datos MongoDB

# Conectar a MongoDB
mongosh

# Crear base de datos
use restaurante_db

# Crear colecciones (opcional, se crean automáticamente)
db.createCollection("clientes")
db.createCollection("reservas")
db.createCollection("facturas")

# Salir
exit

8Migrar Base de Datos Django

# Crear migraciones
python manage.py makemigrations

# Aplicar migraciones
python manage.py migrate
ℹ️ Nota: Django usa SQLite para autenticación. MongoDB se usa para datos de negocio.

9Crear Superusuario

python manage.py createsuperuser

# Ingresar:
# - Username: admin
# - Email: [email protected] (opcional)
# - Password: (tu contraseña segura)

10Crear Mesas Iniciales

Ejecuta el shell de Django:

python manage.py shell

Luego ejecuta este código:

from mongoengine import connect, Document
from mongoengine.fields import IntField, StringField

# Conectar a MongoDB
connect(db='restaurante_db', host='localhost', port=27017)

# Definir modelo Mesa
class Mesa(Document):
    numeroMesa = IntField(required=True, unique=True)
    capacidad = IntField(required=True)
    estado = StringField(default="Disponible")

# Crear mesas
mesas_data = [
    {'numeroMesa': 1, 'capacidad': 2},
    {'numeroMesa': 2, 'capacidad': 4},
    {'numeroMesa': 3, 'capacidad': 4},
    {'numeroMesa': 4, 'capacidad': 6},
    {'numeroMesa': 5, 'capacidad': 4},
    {'numeroMesa': 6, 'capacidad': 4},
    {'numeroMesa': 7, 'capacidad': 2},
    {'numeroMesa': 8, 'capacidad': 8},
    {'numeroMesa': 9, 'capacidad': 4},
    {'numeroMesa': 10, 'capacidad': 2},
    {'numeroMesa': 11, 'capacidad': 4},
    {'numeroMesa': 12, 'capacidad': 6},
]

for data in mesas_data:
    Mesa(**data).save()

print("✅ Mesas creadas exitosamente")
exit()

11Ejecutar el Servidor

python manage.py runserver
🎉 ¡Éxito! El servidor está corriendo en:
  • Frontend: http://127.0.0.1:8000/
  • Panel Admin: http://127.0.0.1:8000/admin/login/

6. Despliegue en Producción

⚠️ Antes de desplegar:
  • Cambiar DEBUG = False en settings.py
  • Configurar ALLOWED_HOSTS
  • Usar variables de entorno para secretos
  • Configurar servidor web (Nginx/Apache)
  • Usar Gunicorn o uWSGI

🚀 Opciones de Despliegue

Opción 1: Heroku

# Instalar Heroku CLI
# Crear Procfile
echo "web: gunicorn restaurante_reservas.wsgi" > Procfile

# Crear requirements.txt
pip freeze > requirements.txt

# Desplegar
heroku create mi-restaurante
git push heroku main

Opción 2: DigitalOcean/AWS

  • Configurar droplet/EC2 con Ubuntu
  • Instalar Nginx + Gunicorn
  • Configurar MongoDB en la nube (Atlas)
  • Configurar SSL con Let's Encrypt

Opción 3: PythonAnywhere

  • Subir código al servidor
  • Configurar Web App
  • Usar MongoDB Atlas (PythonAnywhere no soporta MongoDB local)

7. Solución de Problemas

❌ Error: "No module named 'mongoengine'"

Solución:

pip install mongoengine

❌ Error: "Can't connect to MongoDB"

Solución:

# Verificar que MongoDB está corriendo
mongod --version

# Windows: Iniciar servicio
net start MongoDB

# Linux: Iniciar servicio
sudo systemctl start mongod

❌ Error: "Port 8000 already in use"

Solución:

# Usar otro puerto
python manage.py runserver 8080

# O matar el proceso en 8000
# Windows:
netstat -ano | findstr :8000
taskkill /PID [número] /F

# Linux:
lsof -ti:8000 | xargs kill -9

❌ Error: "TemplateDoesNotExist"

Solución:

  • Verificar que los templates están en app/templates/app/
  • Verificar APP_DIRS = True en settings.py
  • Verificar que la app está en INSTALLED_APPS

❌ Las mesas no se crean automáticamente

Solución: Ejecutar el script de creación de mesas del Paso 10

❌ No puedo hacer login como admin

Solución:

# Crear nuevo superuser
python manage.py createsuperuser

🔍 Modo Debug

Para ver errores detallados:

# settings.py
DEBUG = True

# Luego reiniciar el servidor
python manage.py runserver
